## 1. NanoVNAとSDRの違い、RF測定原理および電波法（微弱無線局）

### 1.1 SDR（受動）とNanoVNA（能動）の決定的差異
* **SDR (Software Defined Radio)**:
  * パッシブ（受動）受信機。外部からアンテナに入力された電波を直交検波（IQサンプリング）してPCへ送る。
  * 受信電力（スカラー量）のスペクトラムは観測できるが、「アンテナが目的周波数で正しく整合（マッチング）しているか」「反射でどれだけ電力を捨てているか」は測定できない。
* **NanoVNA (Vector Network Analyzer)**:
  * アクティブ（能動）測定器。内蔵の周波数シンセサイザから既知の基準高周波信号をアンテナや回路に向けて送出し、跳ね返ってきた波（反射波）および通り抜けた波（透過波）の **「振幅比」と「位相差」を複素ベクトル量** として測定する。

### 1.2 Sパラメータ・反射係数・VSWRの数学的定義

#### 反射係数 $\Gamma$ と $S_{11}$
伝送線路の特性インピーダンス $Z_0$（通常 $50\,\Omega$）に対し、アンテナの複素負荷インピーダンスを $Z_L = R + jX$ とするとき、電圧反射係数 $\Gamma$ およびリターンロス $S_{11}$ は以下で定義される：

$$\Gamma = S_{11} = \frac{Z_L - Z_0}{Z_L + Z_0}$$

$$S_{11} \,[\text{dB}] = 20 \log_{10} |\Gamma|$$

$$\text{VSWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

##### 記号一覧
| 記号 | 物理的意味 | 単位 / 基準値 |
| :--- | :--- | :--- |
| $\Gamma$（ガンマ） | 電圧反射係数（入射波に対する反射波の比率） | 無次元（複素数: $|\Gamma| \le 1$） |
| $S_{11}$ | 入力端子反射係数（リターンロス） | $\text{dB}$（$-15\text{ dB}$ 以下が良好） |
| $Z_0$ | 伝送線路の特性インピーダンス | $\Omega$（純抵抗 $50\,\Omega$） |
| $Z_L$ | アンテナの負荷インピーダンス（$R + jX$） | $\Omega$（$R$: 放射抵抗, $X$: リアクタンス） |
| $\text{VSWR}$ | 電圧定在波比（Voltage Standing Wave Ratio） | 無次元（$1.0 \sim \infty$、$1.5$ 以下が合格） |

##### 日本語での読み解き
* $Z_L = Z_0 = 50\,\Omega$ のとき、$\Gamma = 0$ となり、電波エネルギーは反射することなく $100\%$ アンテナから送受信機へ伝達される。
* インピーダンスが不整合の場合、$|\Gamma| > 0$ となり、アンテナが捉えた微弱信号の一部が端面で反射されて失われる（受信感度の劣化）。

### 1.3 スミスチャートの幾何学的読み解き
NanoVNA は反射係数 $\Gamma$ の実部と虚部を複素平面上にプロットし、正規化インピーダンス $z = Z_L / Z_0$ の軌跡（スミスチャート）を描画する：
1. **中心点 ($1.0 + j0$)**: 理想的な $50\,\Omega$ 純抵抗。反射ゼロ。
2. **中心より上半平面 ($+jX$)**: 誘導性（インダクタンス過剰）。アンテナが物理的に長すぎることを示す。
3. **中心より下半平面 ($-jX$)**: 容量性（キャパシタンス過剰）。アンテナが短すぎることを示す。
4. **手すり近接の影響**: アンテナをベランダの金属手すりに近づけると、浮遊容量によってチャート上の軌跡が下方向へ歪む。NanoVNA を見ながら手すりからの離隔距離を調整することで、ミリ単位でのインピーダンス補正が可能となる。

### 1.4 日本の電波法における法的位置づけ（無免許使用の根拠）
NanoVNA は高周波信号を発生するが、**免許・資格・届出は一切不要（完全合法）** である。

* **電波法 第4条第1項第1号（微弱無線局の特例）**:
  総務省令で定める「極めて微弱な電波を発射する無線局」は免許を要しないと規定されている。
  🔗 [総務省 電波利用ホームページ：微弱無線局](https://www.tele.soumu.go.jp/j/sys/others/wkn/)
* **出力レベルの比較**:
  * NanoVNA の発振出力: 約 $-10\text{ dBm} \sim 0\text{ dBm}$（約 $0.1\text{ mW} \sim 1\text{ mW}$）。
  * Wi-Fi / Bluetooth（特定小電力無線）: 約 $10\text{ mW} \sim 100\text{ mW}$。
  * アマチュア無線機: 数千 $\text{mW} \sim$ 数十万 $\text{mW}$。
* NanoVNA の出力は Wi-Fi の $1/10 \sim 1/100$ 以下であり、数メートル離れれば環境熱雑音に埋もれるレベルであるため、微弱無線局基準に完全に合致する。

## 2. 4条螺旋アンテナ（QFH）の物理特性とベランダ設置の優位性

### 2.1 円偏波（RHCP）と軸比（Axial Ratio）
極軌道衛星（Meteor-M、NOAA、キューブサット）は、地球上空を通過する際に姿勢変化や電離層の **ファラデー回転（Faraday Rotation）** による偏波面回転を受ける。
* **直線偏波アンテナ（ダイポール等）の限界**:
  * 直線偏波で円偏波を受信すると、理論上最低でも $3\text{ dB}$（電力の $50\%$）の偏波損失が生じる。
  * 偏波面が直交した瞬間に $20\text{ dB}$ 以上のクロス偏波フェージング（瞬間的消失）が発生し、高速デジタル信号（QPSK）の復調が破綻する。
* **QFH の優位性**:
  * 4本のヘリックスエレメントが空間的・電気的に $90^\circ$ ずつ位相差を持つため、理想的な **右旋円偏波（RHCP）** を合成。
  * 天頂から低仰角（$15^\circ$）まで軸比（Axial Ratio）が $\le 2\text{ dB}$ に維持され、フェージングなしで連続復調が可能。

### 2.2 前後比（F/B比）と室外機ノイズの物理的遮蔽
QFH アンテナの放射パターンは半球状のカーディオイド（心臓型）であり、**アンテナ底面（下方向）に対する感度が $-15 \sim -20\text{ dB}$（約 $1/30 \sim 1/100$）に低減** される。
* ベランダのエアコン室外機の上に設置した場合、真下に存在するコンプレッサーのインバーターノイズや床面のマルチパス反射波を、アンテナ構造自身が物理的にブラインド（遮蔽）する。

### 2.3 上階ひさしの遮蔽を回避するチルトマウント
ベランダ環境では、上階のコンクリート床により真上（仰角 $70^\circ \sim 90^\circ$）の電波が遮蔽される。
* QFH を垂直に立てるのではなく、カメラ用自由雲台を用いて **ベランダ開口部（北東方向・仰角 $40^\circ \sim 45^\circ$）へ前傾（チルト）固定** する。
* 広角な半球ビーム（半値幅 $120^\circ \sim 140^\circ$）が「見通せる空の窓（Sky Window）」に合致し、手すり内側の専有スペース内で最大のS/N比を実現できる。

## 3. 21cm中性水素線の放射機構と「普通の星」が見えない天体物理学

### 3.1 なぜ太陽ではなく天の川銀河全体なのか（北向きベランダの優位性）
* **水素線の発生源**:
  太陽表面などの超高温環境ではなく、**銀河系の星間空間に漂う冷たい中性水素ガス雲（HI領域: 温度 $10 \sim 100\text{ K}$）** から放射される。
* **北向きベランダの利点**:
  北の空には天の川銀河の主脈である **カシオペア座・白鳥座・ケフェウス座・ペルセウス座** が位置し、周極星領域に近いため一年中沈むことなく観測可能。
* **太陽の位置づけ**:
  太陽はプラズマ電離（HII）により21cm線を出さず、むしろ広帯域熱雑音を放射するため、水素線観測においては視界に入らない夜間や北天の方が有利である。

### 3.2 なぜ個々の恒星（シリウス等）は電波で見えないのか（プラズマ電離と立体角）

#### ① プラズマ電離による中性原子の不在
恒星表面は数千〜数万度と超高温であり、水素は電子と陽子が分離した **電離状態（HIIプラズマ）** にあるため、中性水素原子（HI）の超微細構造遷移自体が存在しない。

#### ② レイリー・ジーンズの法則と微小な立体角
電波帯における熱放射フラックス密度 $S_\nu$ は、レイリー・ジーンズの近似式に従う：

$$S_\nu = \frac{2 k_B T}{\lambda^2} \Omega$$

##### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $S_\nu$ | 受信フラックス密度 | $\text{W}/(\text{m}^2 \cdot \text{Hz})$ (または $\text{Jy}$) |
| $k_B$ | ボルツマン定数 ($1.38 \times 10^{-23}$) | $\text{J}/\text{K}$ |
| $T$ | 天体温度 | $\text{K}$ |
| $\lambda$ | 観測波長 (21cm $= 0.211\text{ m}$) | $\text{m}$ |
| $\Omega$ | 天体の視立体角（地球から見た見かけの面積） | $\text{sr}$（ステラジアン） |

恒星は何光年も彼方にあるため、見かけの立体角 $\Omega$ は $10^{-16}\text{ sr}$ 以下の点光源であり、地球に届く電波フラックス密度はピコ・ジャンスキー単位に落ち込み、世界最大級の電波望遠鏡群（アルマ望遠鏡等）でも検出が極めて困難である。

### 3.3 1100万年に1回の奇跡：超微細構造遷移と放射計方程式
* 中性水素原子の基底状態において、陽子と電子のスピンが平行な高エネルギー準位から、反平行な低エネルギー準位へ反転する際、エネルギー差 $\Delta E = h \nu$（$\nu = 1420.405751\text{ MHz}$、波長 $\lambda \approx 21.1\text{ cm}$）の電波を放出する。
* アインシュタインの自発遷移確率 $A_{10}$ は約 $2.87 \times 10^{-15}\text{ s}^{-1}$（**1原子あたり約1100万年に1回** の遷移頻度）。
* 銀河系全体には約 $10^{67}$ 個もの水素原子が存在するため、ベランダのアンテナを向けて放射計方程式に従い数分間積算（Integration）することで、銀河系の渦状腕の回転速度スペクトルが明確に検出できる。
