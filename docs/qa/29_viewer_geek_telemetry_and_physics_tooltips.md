# 観測ビューア（viewer）の地上局テレメトリ諸元とインタラクティブ物理解説（HUD Popover）の実装

本ドキュメントでは、ベランダ電波観測所のダッシュボード（`satellite-viewer`）において、各衛星通過カードを高密度の地上局コンソール風に拡張し、カーソルホバーやタップによって電波工学・軌道力学・DSP（デジタル信号処理）の物理メカニズムを学べるインタラクティブ解説ツールチップ（HUD Popover）の実装仕様と理論背景を解説する。

---

## 1. 背景と目的

従来の観測カードは「スペクトログラム画像」「観測時刻」「パケット数」「ファイル一覧」というシンプルな表示にとどまっていた。しかし、裏側で動作している SGP4 軌道力学計算エンジンや衛星諸元データベース、WAV 解析エンジンには、**電波伝搬損失、ドップラー偏移、視線速度変化率、開口窓通過幾何**といった高度な物理パラメータが豊富に含まれている。

これらをカード表面に 3×3 の計器風グリッド（HUD テレメトリパネル）として高密度に集約し、各パラメータに**「名称・物理メカニズム・ベランダ観測での意義」**の3段解説を添えることで、日々の観測ログがそのまま生きた電波工学・宇宙物理の教材となるよう設計・実装した。

---

## 2. 9大テレメトリ指標と物理メカニズム詳解

各カード上に表示される 9 項目のテレメトリパラメータと、その背後にある数式および物理・工学的解釈は以下の通りである。

### (1) TCA (Time of Closest Approach / 最接近通過時刻)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $t_{\text{TCA}}$ | 最接近到達時刻 | UTC / JST |
| $r(t)$ | 観測点と衛星の空間位置ベクトル差 | $\text{km}$ |
| $v_r(t)$ | 衛星の相対視線速度（Radial Velocity） | $\text{m/s}$ |

#### 日本語での読み解き
衛星が地上局に最も接近し、空間直線距離が最小となる極値時刻である。衛星が観測点に向かって接近している間は視線速度が負（$v_r < 0$）であり、最接近を境に遠ざかる正（$v_r > 0$）へと符号が反転する境界点（変曲点）にあたる。

#### 数学的展開
空間斜距離 $d(t) = \|r(t)\|$ とすると、最接近条件は距離の1階時間微分がゼロとなる瞬間である：
$$\frac{d}{dt} d(t) = \frac{r(t) \cdot \dot{r}(t)}{\|r(t)\|} = v_r(t) = 0$$

この瞬間に空間幾何減衰が最小となり、電波強度がピークを迎える。

---

### (2) Max Elevation & Azimuth (最大仰角・通過方位)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $El$ | 仰角（Elevation: 水平面からの角度） | 度（${}^\circ$） |
| $Az$ | 方位角（Azimuth: 北基準の時計回り角度） | 度（${}^\circ$） |
| $(e, n, u)$ | Topocentric ENU（東・北・天頂）座標成分 | $\text{km}$ |

#### 日本語での読み解き
局所座標系（ENU）における衛星の最大仰角と、その時の方位角である。

#### 数式
$$El = \arcsin\left(\frac{u}{\sqrt{e^2 + n^2 + u^2}}\right)$$
$$Az = \operatorname{atan2}(e, n) \pmod{360^\circ}$$

北向きベランダ（方位 $250^\circ \sim 110^\circ$、仰角 $25^\circ \sim 60^\circ$）において、最大仰角がこの範囲に収まるパスほど、上階のコンクリート庇やベランダ手すりの遮蔽を避けて直接波を受信できる。

---

### (3) Sky Window Duration (開口窓通過時間)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $T_{\text{window}}$ | 開口窓内の正味滞在時間 | 秒（$\text{s}$） |
| $\text{AOS}_{\text{win}}, \text{LOS}_{\text{win}}$ | 開口窓進入方位・離脱方位 | 度（${}^\circ$） |

#### 日本語での読み解き
南側を建物の鉄筋コンクリートで遮られる北向きベランダ環境において、衛星が直接見通せる幾何学的視野限界内に滞在した正味の時間である。全録音時間（通常 6〜8 分）のうち、実際にデコード可能なチャンスはこの開口窓滞在時間（通常 2〜4 分）に凝縮される。

---

### (4) NORAD Cat ID & Orbit Type (軌道分類)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $\text{Cat ID}$ | NORAD カタログ番号 | 5桁整数 |
| $i$ | 軌道傾斜角（Inclination） | 度（${}^\circ$） |

#### 日本語での読み解き
北米航空宇宙防衛司令部（NORAD）が付与する宇宙物体の固有識別番号と、赤道面に対する軌道面の傾き角 $i$ である。
- **ISS (Cat #25544, $i = 51.6^\circ$)**: 西から東へ傾いて飛ぶため、南西から北東または北西から南東へ斜めに通過する。
- **極軌道衛星 (Meteor-M Cat #59051, FUNcube Cat #39444, $i \approx 98^\circ$ 太陽同期)**: 北極上空から日本上空へと南北に縦断するため、北向きベランダの正面（方位 $0^\circ$ 付近）を絶好のジオメトリで通過する。

---

### (5) Slant Range (斜距離・空間幾何距離)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $d_{\text{min}}$ | TCA 時の最小斜距離 | $\text{km}$ |
| $d_{\text{max}}$ | パス中の最大斜距離 | $\text{km}$ |

#### 日本語での読み解き
地上アンテナから衛星本体までの空間直線距離である。低軌道衛星（高度 400〜850 km）では、地平線現出時（AOS: 約 2000〜2500 km）から真上通過（TCA: 約 500〜700 km）にかけて距離が 3〜5 倍も劇的に変化する。

---

### (6) FSPL (Free Space Path Loss / 自由空間伝搬損失)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $\text{FSPL}$ | 自由空間伝搬損失 | $\text{dB}$ |
| $d_{\text{km}}$ | 伝搬距離 | $\text{km}$ |
| $f_{\text{MHz}}$ | 送信中心周波数 | $\text{MHz}$ |
| $c$ | 光速（$2.99792458 \times 10^8$） | $\text{m/s}$ |

#### 日本語での読み解き
等方性アンテナから放射された電波エネルギーが、真空中を球面状に拡散する過程で単位面積あたりの電力が距離の2乗に反比例して減衰する物理現象である。

#### 数学的展開
球面の表面積 $S = 4\pi d^2$ および等方性アンテナの実効開口面積 $A_e = \frac{\lambda^2}{4\pi} = \frac{c^2}{4\pi f^2}$ より、送受信電力比（損失比）は：
$$\frac{P_r}{P_t} = \frac{A_e}{4\pi d^2} = \left(\frac{c}{4\pi d f}\right)^2$$

これを常用対数（デシベル表示: $\text{FSPL} = -10\log_{10}(P_r/P_t)$）に変換すると：
$$\text{FSPL} = 20\log_{10}(d) + 20\log_{10}(f) + 20\log_{10}\left(\frac{4\pi}{c}\right)$$
単位を $d \to [\text{km}], f \to [\text{MHz}]$ に換算すると定数項が $32.44$ となり、実用公式が得られる：
$$\text{FSPL} = 20\log_{10}(d_{\text{km}}) + 20\log_{10}(f_{\text{MHz}}) + 32.44 \quad [\text{dB}]$$

#### ベランダ観測での直感イメージ
距離が 2000 km から 600 km へ近づくと、$\Delta \text{FSPL} \approx 20\log_{10}(2000/600) \approx 10.5\text{ dB}$（電力比にして約 11 倍）もの受信電力差が生じる。スペクトログラム上で信号強度が山なりに盛り上がる主因がこの幾何学的伝搬損失の推移である。

---

### (7) Doppler Shift & $df/dt$ (ドップラー周波数偏移と変化率)

#### 記号一覧
| 記号 | 物理的意味 | 単位 |
| :--- | :--- | :--- |
| $\Delta f(t)$ | ドップラー周波数偏移 | $\text{Hz}$ |
| $f_0$ | 送信中心周波数 | $\text{Hz}$ |
| $v_r(t)$ | 相対視線速度 | $\text{m/s}$ |
| $\frac{df}{dt}$ | TCA における周波数変化率 | $\text{Hz/s}$ |

#### 日本語での読み解き
時速約 28,000 km（約 7.5 km/s）で周回する衛星の視線速度により、接近時は周波数が高く、離脱時は低くシフトする現象である。

#### 数式
$$\Delta f(t) = -f_0 \frac{v_r(t)}{c}$$

145 MHz 帯（VHF）の低軌道衛星では最大偏移幅 $\Delta f_{\text{max}} \approx \pm 3.5\text{ kHz}$ に達する。最接近（TCA）の瞬間に視線速度の変化率が極大となり、周波数変化率 $\frac{df}{dt}$（通常 $-30 \sim -50\text{ Hz/s}$）が最も急峻な傾き（S字カーブの変曲点）を描く。

---

### (8) Protocol & Modulation (物理層変調・通信規格)

- **ISS APRS**: $145.825\text{ MHz}$, $1200\text{ bps}$ AFSK（Bell 202: マーク $1200\text{ Hz}$, スペース $2200\text{ Hz}$）、AX.25 データリンクフレーム。
- **CubeSat (FUNcube-1)**: $145.935\text{ MHz}$, $1200\text{ bps}$ BPSK（二位相偏移変調）。低電力テレメトリに特化。
- **気象衛星 (Meteor-M)**: $137.900\text{ MHz}$, $72\text{ kbps}$ QPSK（四位相偏移変調）。畳み込み符号 FEC とリードソロモン符号による高速画像伝送。

---

### (9) Decode Stats & CRC (復号実績)

受信した電波からノイズを取り除き、フレームチェックシーケンス（CRC-16-CCITT）を通過した正常パケット数である。ベランダの手すり反射（マルチパス）や都市ノイズに打ち勝ち、1ビットの誤りもなく成立した正味の成果を示す。

## 3. UI/UX 設計とインタラクション仕様

### (1) HUD 風 3×3 テレメトリグリッド
- 背景色: 濃紺の半透明（`rgba(8, 14, 26, 0.75)`）
- ボーダー: 薄いサイアン（`rgba(56, 189, 248, 0.25)`）
- フォント: 計器風等幅フォント（`ui-monospace, Consolas`）
- レスポンシブ: デスクトップでは 3 列グリッド、モバイル（幅 680px 未満）では 1 列に自動適応。

### (2) 画面端見切れ防止スマートツールチップ
デスクトップではカーソルホバー、モバイルでは各項目の `ⓘ` タップで解説ポップオーバーが展開する。
画面端で見切れないよう、列ごとに CSS ポジショニングを自動最適化している：
- **左列（Col 1）**: `left: 0; transform: none;`（左揃え）
- **中央列（Col 2）**: `left: 50%; transform: translateX(-50%);`（中央揃え）
- **右列（Col 3）**: `right: 0; left: auto; transform: none;`（右揃え）

### (3) 最新パケットのインラインプレビュー
パケット（APRS 等）が復号された場合、カード内にターミナル風ボックス（黒背景に緑文字）で最新フレームの送信元・宛先・ペイロード文字列をインライン表示する。
