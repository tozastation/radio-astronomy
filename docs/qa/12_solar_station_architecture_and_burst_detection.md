# ☀️ 太陽電波観測ステーション（`solar-station`）アーキテクチャとバースト検知DSP詳解

本ドキュメントでは、**RTL-SDR Blog V4** および付属の**マグネットベース伸縮ホイップアンテナ**（金属板グラウンド吸着）を活用した、自律型太陽電波観測ステーション（`apps/ground-station/src/bin/solar_station.rs`）のシステム構成、70MHz帯共振電磁気学、リアルタイムDSP積算、MADロバスト統計によるフレアバースト検知アルゴリズム、およびSRE的データ永続化設計を詳細に解説します。

## 1. 全体アーキテクチャと観測パイプライン

太陽表面でフレア（磁気リコネクション）が発生すると、加速された超高速電子線がコロナ中を駆け抜ける過程で、局所プラズマ周波数 $f_p \propto \sqrt{n_e}$ の強力なプラズマ電波バースト（Type II / Type III バースト）が放射されます。  
地球での受信電力は **$10^5 \sim 10^9 \text{ Jy}$（数十万〜数十億ジャンスキー）** に達し、ベランダの無指向性アンテナでも普段の背景雑音を **10〜20 dB（10倍〜100倍）吹き飛ばす強烈なシグナル** として捉えられます。

## 2. 付属アンテナの電磁気学（なぜ 1m 伸ばして金属板につけると 70MHz に共振するのか？）

### 1/4 波長モノポールアンテナの物理
付属のアンテナは、底面が強力マグネットになった台座と、ネジ込み式の伸縮金属ロッド（テレスコピックエレメント）で構成されています。

$$L = \frac{\lambda}{4} = \frac{c}{4 f}$$

| 記号 | 物理的意味 | 代表値 | 単位 |
| :--- | :--- | :--- | :--- |
| $L$ | アンテナエレメントの物理長 | $1.00$（最大伸長時） | $\text{m}$ |
| $\lambda$ | 電波の波長 | $4.00$ | $\text{m}$ |
| $c$ | 光速 | $2.9979 \times 10^8$ | $\text{m/s}$ |
| $f$ | 共振周波数 | $\approx \mathbf{75.0}$ | $\text{MHz}$ |

#### 日本語での読み解き
電波が導体内を往復する際、アンテナの先端で反射して戻ってくる波と新しく入ってくる波が強め合い、給電点（アンテナの根元）で電流が最大・電圧が最小となる「共振状態」が生まれます。エレメント長が波長のちょうど 1/4 であるとき、インピーダンスが純抵抗（約 $36.5\ \Omega$）に近づき、高周波エネルギーが同軸ケーブルへ最も効率よく吸い込まれます。

#### 金属板（グラウンドプレーン）の必須性
モノポールアンテナは単体では「片側の極」しか持ちません。底面の磁石をお菓子のスチール缶やエアコン室外機の天板にくっつけることで、**金属板の内部に逆極性の「鏡像電流（イメージカレント）」** が励振されます。  
これにより、空間的には 1本の棒であっても、電磁気学的には **「長さ $2L = \frac{\lambda}{2}$ の半波長ダイポールアンテナ」** と完全に等価になり、インピーダンス整合と高感度受信が成立します。

## 3. リアルタイムDSPとMADロバスト動的しきい値検知の数理

毎秒 2,400,000 サンプルの生IQデータ（4.8 MB/s）から、太陽フレアの立ち上がり（インパルシブフェーズ）を瞬時に検知するアルゴリズムです。

### 1. 1024ビン FFT と 1秒積算
1. **周波数分解能**:
   $$\Delta f = \frac{f_s}{N_{\text{fft}}} = \frac{2,400,000 \text{ Hz}}{1024} \approx 2.34 \text{ kHz}$$
2. **ハミング窓（Hamming Window）**:
   $$w[n] = 0.54 - 0.46 \cos\left( \frac{2\pi n}{1023} \right)$$
3. **1秒積算平均化**:
   1秒間に約 $N_{\text{blocks}} = 2,343$ 回の 1024点 FFT を実行し、パワースペクトルを加算平均：
   $$\bar{P}[k] = \frac{1}{2343} \sum_{m=1}^{2343} |X_m[k]|^2$$
   これにより、ガウス白色熱雑音の標準偏差が $\frac{1}{\sqrt{2343}} \approx \frac{1}{48.4}$（約 **17 dB 改善**）に平滑化され、微弱なフレアのシグナルが浮かび上がります。

### 2. MAD（中央値絶対偏差）ロバスト統計
気温変化や地球の自転に伴う背景銀河ノイズの緩やかな変動があるため、固定のしきい値では誤検知が生じます。  
直近 300秒（5分間）の総電力履歴 $\{P_1, P_2, \dots, P_{300}\}$ から、外れ値に極めて強いロバスト統計量を算出します：

$$\text{Median} = \text{median}(\{P_i\})$$
$$\text{MAD} = \text{median}(\{|P_i - \text{Median}|\})$$
$$\sigma_{\text{robust}} = 1.4826 \times \text{MAD}$$

| 記号 | 統計・物理的意味 | 計算式 / 代表値 |
| :--- | :--- | :--- |
| $\text{Median}$ | 背景ノイズフロアの中央値 | データ中央値（外れ値に影響されない） |
| $\text{MAD}$ | 偏差の絶対値の中央値 | スケール推定値 |
| $1.4826$ | 正規分布補正係数 | ガウス分布において $\text{MAD} \times 1.4826 = \sigma$ となる係数 |
| $\sigma_{\text{robust}}$ | ロバスト標準偏差 | ノイズフロアの純粋な揺らぎ幅 |

### 3. バースト判定（トリガー条件）
以下の2条件が同時に成立した瞬間にトリガーが発火します：
1. **絶対強度超過**:
   $$P_{\text{total}} > \text{Median} + (k \times \sigma_{\text{robust}}) \quad (k = 4.0 \sim 5.0)$$
2. **急上昇率（時間微分 $\frac{dP}{dt}$）**:
   $$\frac{dP_{\text{total}}}{dt} \ge +3.0 \text{ dB/s}$$

太陽フレアは数秒間で一気に 6〜20 dB 跳ね上がるため、時間微分条件を組み合わせることで、**「日中のゆっくりとした気温上昇によるベースライン変動」を 100% 排除** します。

## 4. SRE的省リソース設計（ストレージ極小化）

生IQデータ（4.8 MB/s = **約 415 GB/日**）を保存すると、小型エッジPC（GPD Pocket3）のSSDは数日で枯渇します。  
本システムでは **生IQをメモリ内でFFT後に即座に破棄（Zero-Persistence IQ）** し、集約メトリクスのみを永続化します：

| データ種別 | 保存形式 | 記録タイミング | 1日あたりの容量 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| **生IQデータ** | メモリ上のみ | 常時（ディスク非保存） | 0 MB | リアルタイムFFT専用（破棄） |
| **1秒集約メトリクス** | 追記型 JSON Lines | 毎秒（1レコード約100B） | **約 8 MB / 日** | DuckDB での時系列ライトカーブ分析 |
| **フレアイベント画像** | PNG (800x400) | バースト検知時のみ | **数百 KB / 回** | Discord 通知およびイベントアーカイブ |
| **日別全体スペクトログラム** | PNG (1920x1080) | 日没（観測終了）時に1枚 | **約 2 MB / 日** | 1日の太陽活動の俯瞰・比較 |

- **合計ストレージフットプリント**: **約 10 MB / 日（1年間常時観測してもわずか 3.6 GB）**
- GPD Pocket3 のローカルSSDだけで、メンテナンスフリーで数年分の太陽観測履歴を余裕で常時蓄積できます。

## 5. CLI操作と観測実行手順

### 1. 動作確認（ドライランモード）
SDRハードウェアを接続していない開発環境でも、疑似IQ信号を用いたシミュレーションが可能です：

```bash
# 疑似IQストリームで10秒間の動作確認
cargo run --bin solar-station -- --dry-run
```

### 2. 本番観測の開始（日照連動モード）
ベランダにアンテナを設置し、RTL-SDR Blog V4 を接続して起動します：

```bash
# 日照時間帯 (El >= 5°) に自動で受信・夜間は自動待機
cargo run --bin solar-station -- -c apps/ground-station/config.toml
```

### 3. 24時間連続観測モード
夜間の銀河背景雑音や電離層擾乱も継続してロギングする場合：

```bash
# 日没時も停止せず24時間連続観測
cargo run --bin solar-station -- -c apps/ground-station/config.toml --continuous
```
