## 1. 📻 ハードウェア & 無線工学 (SDR/RF)

<a id="sdr"></a>
### SDR (Software Defined Radio / ソフトウェア無線)
- **概要**: 従来は電子回路（コイル、コンデンサ、ミキサー、専用ASIC）で固定的に行っていた周波数の選局・復調・フィルタリング・増幅を、**ソフトウェア（CPUやGPU上のコード）で自由に制御・処理する無線技術**。
- **エンジニア目線**: 「プログラマブルなNIC/キャプチャカード」。コードを書き換えるだけで、FMラジオ受信機にも、航空無線（ADS-B）デコーダにも、電波望遠鏡にも変身します。

<a id="bias-t"></a>
### Bias-T (Bias Tee / バイアスティー)
- **概要**: 同軸アンテナケーブルの中に **「高周波電波信号（RF）」** と **「直流電源（DC 4.5V）」** を重畳して同時に流す仕組み。
- **エンジニア目線**: ネットワークにおける **PoE (Power over Ethernet)** のアンテナ同軸線版。屋外やベランダに設置したLNA（アンプ）に対して、専用の電源線を引かずに同軸ケーブル1本で電力を供給できます。

<a id="lna"></a>
### LNA (Low Noise Amplifier / 低雑音増幅器)
- **概要**: アンテナが捉えた微弱な電波を、**「回路自身の熱雑音を極力増やさずに」** 初段で大きく増幅する特殊なアンプ。
- **重要性 (Friisの公式)**: 受信機システム全体のノイズレベルは「最初の1段目のアンプのノイズ」でほぼ決まります。そのため、同軸ケーブルで引き回して減衰する前の「アンテナ直下」にLNAを置くのが電波天文学の鉄則です。

<a id="bpf"></a>
### BPF (Band Pass Filter / 帯域通過フィルタ)
- **概要**: 観測したい特定の周波数帯（例: 1420 MHz 付近）の電波だけを通過させ、それ以外の周波数（強力なWi-Fi、5G/LTE携帯電波など）を強力に減衰・遮断するフィルター。
- **エンジニア目線**: ファイアウォールやパケットフィルタリングの物理版。強力な妨害波によってSDRのADCが飽和（サチる）のを防ぎます。

<a id="tcxo"></a>
### TCXO (Temperature Compensated Crystal Oscillator / 温度補償水晶発振器)
- **概要**: 周囲の温度変化（冬の寒さや夏の暑さ、回路の発熱）によるクロック周波数のズレ（ドリフト）を、温度補償回路によって極小（±1 PPM以下）に抑えた高精度な水晶発振器。
- **エンジニア目線**: 高精度なNTP/PTPクロック。周波数がズレないため、ドップラーシフトによる数kHzの速度変化を正確に測定できます。

<a id="msps"></a>
### MSPS (Mega Samples Per Second / メガサンプル毎秒)
- **概要**: 1秒間にADCが信号をサンプリング（標本化）する回数。
- **例**: $2.4 \text{ MSPS} = \text{毎秒 240万回の複素サンプリング}$。複素IQ信号の場合、サンプリングレート＝受信可能な瞬時帯域幅（$2.4 \text{ MHz}$）になります。

## 2. 🌌 天文学 & 宇宙物理 (Astro/Physics)

<a id="21cm"></a>
### 21cm線 / HI線 (Neutral Hydrogen Line / 中性水素輝線)
- **概要**: 宇宙空間に漂う冷たい中性水素原子（H I）が、陽子と電子のスピンが平行な状態から反平行な状態へ自発的に反転（スピン反転遷移）する際に放出する電磁波。
- **周波数**: **$1420.40575 \text{ MHz}$**（波長 $\approx 21.1 \text{ cm}$）。
- **天文学的意義**: 宇宙の塵（星間ダスト）に邪魔されずに銀河全体を透過するため、**天の川銀河の腕の渦巻き構造や回転速度をマッピングできる電波天文学最大の武器**です。

<a id="doppler"></a>
### ドップラー効果 (Doppler Effect)
- **概要**: 電波を発する天体と地球との間の相対運動により、観測される電波の周波数が本来の静止周波数 $\nu_0$（1420.405 MHz）からシフトする現象。
  - **青方偏移 (Blue Shift)**: 天体が近づいている $\to$ 周波数が高くなる ($\nu > \nu_0$)
  - **赤方偏移 (Red Shift)**: 天体が遠ざかっている $\to$ 周波数が低くなる ($\nu < \nu_0$)
- **視線速度の導出**: $\frac{\Delta \nu}{\nu_0} \approx -\frac{v}{c}$ から、秒速数百kmで動く星間ガスの運動速度を逆算します。

<a id="lsr"></a>
### LSR (Local Standard of Rest / 局所静止座標系) 補正
- **概要**: 測定された生の視線速度から、**「地球の自転（~0.4 km/s）」「地球の公転（~30 km/s）」「太陽系の銀河内運動（~20 km/s）」** を差し引く座標変換・速度補正計算。
- **エンジニア目線**: タイムスタンプのタイムゾーン補正（UTC/JST変換）や、分散トレーシングにおけるネットワークレイテンシのオフセット補正のようなもの。補正して初めて「銀河系内の純粋なガスの速度」が得られます。

<a id="rotation-curve"></a>
### 銀河回転曲線 (Galactic Rotation Curve)
- **概要**: 銀河中心からの距離 $R$ と、その位置にある星間ガスや星の回転速度 $V(R)$ の関係を示したグラフ。
- **ダークマター（暗黒物質）の証拠**: ケプラーの法則（目に見える恒星やガスの重力のみ）では外側ほど速度が落ちるはずですが、実際の21cm線観測では外側でも速度が落ちない（フラットな回転曲線）。これにより、**宇宙には目に見えない莫大な質量（ダークマターハロー）が存在することが証明されました**。

<a id="radiometer"></a>
### 放射計方程式 (Radiometer Equation)
- **概要**: 電波天文学における最小検出可能ノイズ温度 $\Delta T$ を表す基本方程式：
  $$\Delta T = \frac{T_{\text{sys}}}{\sqrt{B \cdot \tau}}$$
  （$T_{\text{sys}}$: システム雑音温度, $B$: 帯域幅, $\tau$: 積算時間）
- **エンジニア目線**: 「ノイズに埋もれた微弱シグナルでも、積算時間 $\tau$ を長く（平均化）すればノイズ標準偏差が $1/\sqrt{\tau}$ で減少し、必ず検出できる」という理論的保証。

<a id="brightness-temp"></a>
### 輝度温度 (Brightness Temperature, $T_b$)
- **概要**: 電波の強さ（エネルギーフラックス）を、レイリー・ジーンズの法則に基づいて「同じ強度の電波を放射する黒体の絶対温度（ケルビン $[K]$）」に換算した単位。電波天文学では電波の強さをワットではなく $[K]$ で表すのが一般的です。

## 3. 📊 デジタル信号処理 (DSP & Math)

<a id="iq"></a>
### IQ信号 (In-phase & Quadrature / 直交信号)
- **概要**: 搬送波と同相（In-phase: $I$）の成分と、90度位相が遅れた（Quadrature: $Q$）成分を、複素数 $x[n] = I[n] + j Q[n]$ としてペアで表現した信号。
- **エンジニア目線**: 信号の「瞬時の大きさ（振幅）」と「回転の向き・位相」を保持する2次元ベクトル。実数だけでは区別できない「$+f$（正の周波数）」と「$-f$（負の周波数）」を完全に分離できます。

<a id="fft"></a>
### FFT (Fast Fourier Transform / 高速フーリエ変換)
- **概要**: 時間領域の波形データ（IQ時系列）を、どの周波数成分がどれくらい含まれているか（周波数スペクトル）に高速変換するアルゴリズム（計算量 $O(N \log N)$）。

<a id="window"></a>
### 窓関数 (Window Function)
- **概要**: 連続する信号をFFT点数 $N$（例: 2048点）で切り出す際に生じる端点の不連続性（急激なステップ変化）をなだらかにするために乗算する関数（Hann窓、Blackman窓など）。
- **エンジニア目線**: 「スペクトル漏れ（Spectral Leakage）」というノイズの滲みを抑え、微弱な信号を浮き彫りにするための前処理フィルタ。

<a id="integration"></a>
### 積算 (Integration / Averaging)
- **概要**: 1秒間に何百回・何千回と計算したFFTパワースペクトル（PSD）を足し合わせて平均化する処理。
- **エンジニア目線**: メトリクスのダウンサンプリングや集約（Rollup）。これにより、データ量をギガバイト単位からキロバイト単位に圧縮しながらSNR（信号対雑音比）を劇的に向上させます。

<a id="waterfall"></a>
### ウォーターフォール (Waterfall Display / Spectrogram)
- **概要**: **「横軸＝周波数」「縦軸＝時間」「ピクセルの色・輝度＝電波の強さ」** で表した2次元ヒートマップ表示。電波の周波数変化や突発的なバーストが滝のように流れて見えます。

## 4. 🧭 天球座標系 & 観測手法 (Coordinates)

<a id="horizontal-coord"></a>
### 地平座標系 (Horizontal Coordinates: Az / El)
- **方位角 (Azimuth, Az)**: 北=0°, 東=90°, 南=180°, 西=270°
- **仰角 / 高度 (Elevation, El)**: 地平線=0°, 天頂=90°
- **意味**: 望遠鏡・アンテナを物理的に向ける実際の角度。地球の自転や観測場所によって刻々変化します。

<a id="equatorial-coord"></a>
### 赤道座標系 (Equatorial Coordinates: RA / Dec)
- **赤経 (Right Ascension, RA)**: 春分点を基準とする角度（時角 $0^h \sim 24^h$）
- **赤緯 (Declination, Dec)**: 天の赤道を基準とする角度（$-90^\circ \sim +90^\circ$）
- **意味**: 天球上の恒星や天体の位置を表す宇宙の標準緯度経度。

<a id="galactic-coord"></a>
### 銀河座標系 (Galactic Coordinates: $l$ / $b$)
- **銀経 (Galactic Longitude, $l$)**: 銀河中心（いて座方向）を $0^\circ$ とし、天の川の円盤に沿って反時計回りに $0^\circ \sim 360^\circ$
- **銀緯 (Galactic Latitude, $b$)**: 天の川の円盤面を $0^\circ$ とし、銀河北極を $+90^\circ$
- **意味**: 天の川銀河の構造を解析するための専用座標系。21cm線観測では $b \approx 0^\circ$（銀河面）に沿って銀経 $l$ をスキャンします。

<a id="drift-scan"></a>
### ドリフトスキャン (Drift Scan)
- **概要**: アンテナを天頂などの一定方位に固定し、**「地球の自転」を利用して天球がアンテナの視野を通過するのを待つ** 観測手法。
- **メリット**: アンテナを電動で自動追尾（トラッキング）するモーター機構が不要で、固定設置したアンテナで24時間放置するだけで天の川全域の断面スキャンデータが得られます。

## 5. 📡 衛星通信 & プロトコルデコード (Satellite Comms & Protocol)

<a id="oqpsk"></a>
### OQPSK (Offset Quadrature Phase Shift Keying / オフセット四相位相変調)
- **概要**: 複素平面上の4点（00, 01, 11, 10）にビットを割り当てるQPSKにおいて、Qチャンネルの遷移タイミングをIチャンネルに対して $1/2$ シンボル周期ずらした変調方式。
- **エンジニア目線**: 「信号振幅のゼロ通過防止リミッター」。通常のQPSKは位相が原点（0ボルト）を横切る際に送信アンプの非線形歪みを生じますが、OQPSKは原点を迂回するため、低消費電力な衛星トランスミッタでも電波の波形が崩れません。Meteor-M 等のデジタル気象衛星で採用されています。

<a id="viterbi"></a>
### ビタビ復号 (Viterbi Algorithm / 畳み込み復号)
- **概要**: 送信側で過去のビット列との畳み込み演算によって冗長性を持たせた信号（畳み込み符号）から、動的計画法（Dynamic Programming）を用いて最も確率の高い元のビット列を逆算する復号アルゴリズム。
- **エンジニア目線**: 「最短経路探索（ダイクストラ法）によるビット誤り修復」。受信したアナログ電波の電圧を単に0/1判定するのではなく、「0.8くらい1に近い」という尤度（重み）を保持したままトレリス状態遷移グラフを探索するため、劣悪なノイズの中でも驚異的にビット化けを修復します。

<a id="reed-solomon"></a>
### リード・ソロモン符号 (Reed-Solomon Code)
- **概要**: ガロア体 $\text{GF}(2^8)$ 上の多項式補間を用いた、バイト単位（シンボル単位）のブロック誤り訂正符号。
- **代表例**: $\text{RS}(255, 223)$。255バイトのブロック内に32バイトのパリティを含み、最大16バイトまでのあらゆる破損（バースト誤り）を100%自動修復します。
- **エンジニア目線**: QRコードやCD/DVD、RAID-6のパリティ計算にも使われている強力なFECアルゴリズム。宇宙通信ではビタビ復号で取り切れなかった集中的なビット化けをトドメで完治させます。

<a id="cadu"></a>
### CADU (Channel Access Data Unit)
- **概要**: 宇宙データシステム諮問委員会（CCSDS）が策定した、宇宙通信データリンク層の固定長物理フレーム（通常1024バイト）。
- **同期ワード**: 先頭に `0x1ACFFC1D`（32ビット）のマジックナンバーが配置され、ビットストリームの中からフレームの境界（行頭・パケット先頭）を確定します。
- **エンジニア目線**: Ethernetフレームのプリアンブル＋MACヘッダ、あるいはHTTP/2のフレームヘッダに相当します。

<a id="ccsds"></a>
### CCSDS (Consultative Committee for Space Data Systems / 宇宙データシステム諮問委員会)
- **概要**: NASA、ESA、JAXA、Roscosmos など世界の主要宇宙機関が策定している、宇宙機通信・パケット伝送の世界標準規格。
- **エンジニア目線**: 宇宙通信界の「IETF / RFC」。スペースパケットプロトコルは、APID（アプリケーション識別子＝URL/ポート相当）やシーケンス番号を持ち、TCP/IPと極めて近い階層構造を持っています。

<a id="ssdv"></a>
### SSDV (Slow Scan Digital Video)
- **概要**: パケット無線通信（CubeSatや成層圏気球）向けに開発された、パケット欠落耐性を持つ画像伝送プロトコル。
- **エンジニア目線**: 「耐障害性JPEGストリーミング」。通常のJPEGは1バイト欠落しただけでファイル全体が展開不能になりますが、SSDVは $16 \times 16$ のMCUブロックごとに座標ヘッダと独立したReed-Solomon誤り訂正パリティを持つため、受信パケットが歯抜けになっても届いた部分だけでジグソーパズルのように画像を部分復元できます。

<a id="vis-code"></a>
### VISコード (Vertical Interval Signaling)
- **概要**: SSTV（低速度走査テレビジョン）において、画像走査を開始する直前に送信されるデジタルヘッダ信号。
- **エンジニア目線**: HTTPの `Content-Type: image/x-sstv-robot36` ヘッダ。1200Hzの周波数シフトでモード番号（Robot 36, PD120 等）を送信し、受信機が事前の手動設定なしに走査タイミングと色変換パーサーを自動選択できるようにします。
