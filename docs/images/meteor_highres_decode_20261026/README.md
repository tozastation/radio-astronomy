## 🔬 物理・工学的ポイント（初復調との比較）

1. **走査線数が 40 行から 792 行へと飛躍**:
   - MSU-MR 放射計は東西方向（X軸: $1,568\text{ px}$）を回転鏡で一気に走査し、衛星の軌道進行（秒速約 $7.5\text{ km}$）によって Y 軸が進む「ラインスキャナ方式」です。
   - 初復調時（10/25）はロック時間が約 10 秒にとどまり 40 行（帯状）でしたが、本観測（10/26）では天頂パス（$\text{El}=84.9^\circ$）において 3 分以上にわたり安定同期が継続したため、**南北約 $1,500\text{ km}$ に相当する 792 行の長大画像** が得られました。
2. **`--dc_block true` とアンテナ姿勢刷新の有効性**:
   - RTL-SDR 特有の $0\text{ Hz}$ DC スパイクを除去したことで、Costas ループが偽の搬送波にトラップされるサイクルスリップを回避。
   - ベランダ手すり反射（Lloyd's Mirror 効果）によるマルチパス干渉フェージングの谷間でも同期が外れにくくなっています。
